# neuro-ds-journey
Documenting my path toward research-ready data science skills for cognitive & computational neuroscience.

## About
I'm building data science competency aimed at cognitive and computational 
neuroscience research, with the goal of developing a career-worthy, portfolio-backed 
skill set. This repo tracks projects, notes, and progress along an 18-month 
self-study roadmap.

## Roadmap
- Phase 1 (Month 1-3): Python, SQL, statistics fundamentals
- Phase 2 (Month 4-6): Math foundations, signal processing, experimental design
- Phase 3 (Month 7-9): Computational neuroscience core, EEG/fMRI preprocessing
- Phase 4 (Month 10-12): NeuroAI & deep learning
- Phase 5 (Month 13-15): Reproducible research & scientific computing
- Phase 6 (Month 16-18): Research portfolio & career prep

## Structure
- `notebooks/` — exploratory work and exercises
- `projects/` — standalone projects, one folder each
- `notes/` — study notes by topic

## Setup
conda env create -f environment.yml
